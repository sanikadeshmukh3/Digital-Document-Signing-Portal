# Load order rationale:
#   - Reference/core/relationship tables, then constraints+indexes.

#     functions); functions load before procedures (procedures
#     call the functions); triggers last in programmability.
#   - Security roles/grants, then seed data, then validation.
#   - Validation runs last so object + data checks and smoke tests
#     execute against the fully built, seeded database.
#
# NOTE: the on-disk programmability folder is spelled
#       "02_programability" (single 'm'); paths below match disk.
